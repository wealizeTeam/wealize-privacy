계정 삭제 안내

wealize 앱의 계정과 개인정보를 삭제하는 방법

앱에서 직접 삭제하기

  1. wealize 앱에 로그인합니다.
  2. 홈 화면 오른쪽 위의 메뉴(☰)를 엽니다.
  3. 회원 탈퇴를 누릅니다.
  4. 가입한 이메일로 받은 6자리 인증번호를 입력합니다.
  5. 안내 창에서 탈퇴하기를 눌러 확인하면 삭제가 끝납니다.

삭제되는 정보

탈퇴하면 아래 정보가 즉시 삭제되며 되돌릴 수 없습니다.

  • 계정 정보(이메일 주소, 암호화된 비밀번호, 닉네임, 약관 동의 기록)
  • 로그인 세션과 이메일 인증 기록
  • 학습 성향 설문 응답과 추천 결과
  • 학습 기록(선택한 학습방법, 진도, 제출 답안, 능력 추정 결과)

모든 이용자가 함께 보는 학습 콘텐츠는 개인정보가 아니므로 유지됩니다. 같은 이메일로 다시 가입하면 새 계정으로 시작합니다.

앱을 사용할 수 없을 때

로그인할 수 없거나 앱을 삭제한 경우에는 가입한 이메일 주소를 적어 dadadamarine@gmail.com으로 삭제를 요청해 주세요. 본인 확인 후 지체 없이 삭제합니다.
